# Brain Tumor MRI Classifier Using CNN

## Overview
An end-to-end deep learning pipeline that classifies brain tumors from MRI scans. This project implements a Convolutional Neural Network (CNN) to assist in automated medical image analysis.

## Developer
**Abdullah Ghazanfar** - Python Developer | AI/ML Researcher

## Tech Stack
* **Language:** Python
* **Libraries:** TensorFlow, Keras, NumPy, Matplotlib
* **Environment:** Google Colab
* **Data Source:** Kaggle API

## Dataset
The model was trained on a Kaggle dataset of MRI scans. It processes the raw image data and utilizes data augmentation techniques to improve model generalization.

## How to Run
1. Clone this repository.
2. Open the notebook in Google Colab.
3. Ensure your Kaggle API keys are set up to download the dataset.
4. Run all cells to train the model and view the evaluation graphs.
